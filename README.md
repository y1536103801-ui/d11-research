# 男护大促调研助手 · Mac 版

给 Mac 上的 Codex 和 WorkBuddy 加一个「双十一调研」技能。告诉它要调研哪款商品，它可以找候选图让你认款，整理你提供的图片、商品页和优惠资料，最后导出带图 Word、证据表和一张待补清单。无需单独配置模型 API Key。

**[下载 Mac 安装包（ZIP）](https://github.com/y1536103801-ui/d11-research/releases/latest/download/d11-research-mac.zip)**　·　**[通俗上手指南](docs/上手指南.md)**

## 第一次使用

1. 下载并解压 ZIP，双击文件夹里的 `install-mac.command`。只用 Codex 或只用 WorkBuddy 都可以。看到「安装完成」再关窗口。
2. 在你的 Mac 上打开 Codex 或 WorkBuddy，选择一个能保存文件的本地工作文件夹，开一段**新对话**。
3. 把下面这句话发给它。没有商品链接或 Excel 也可以开始。

> 用 d11-research 帮我调研今年双十一的男士控油洁面，先看天猫和抖音。请先找候选商品，给我看图片、品名和规格，让我认款。没有页面证据的价格和优惠标成待补，最后把 Word 和图片保存到当前工作文件夹。

熟悉 Git 的人也可以在终端安装：

```bash
git clone https://github.com/y1536103801-ui/d11-research.git
cd d11-research
bash install-mac.command
```

## 能拿到什么

| 产物 | 用法 |
| --- | --- |
| 候选清单 | 看图认款，区分单支、套装、不同容量和不同包装。 |
| 两套图片目录 | 已核实的活动原图归入「双十一」；已证明当前在用的常规图归入「产品图（更新）」。 |
| 带图 Word、证据表、待补清单 | 对照平台活动、优惠、价格与竞品；可以回查来源、观察时间和适用条件。 |

**当前实测边界：** 已实现公开页面采集和字段核对，但天猫、抖音尚未完成“同一款商品的规格、主图、活动价、优惠四项与真实页面全部对应”的验收。遇到无法读取的页面，可以先做资料整理，缺的字段会列出来。官网参考图、搜索摘要和宣传到手价都不能证明渠道成交价。

只想先看看效果？在新对话说：「用 d11-research 跑一次离线演示，告诉我生成的 Word 在哪里。」演示使用虚构商品图，不访问电商网站。
