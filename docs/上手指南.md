# 在另一台 Mac 上开始第一份调研

你只需要一台 Mac，以及能使用的 Codex 或 WorkBuddy 桌面端。没有商品链接和表格也能开始。第一次可以先看演示，正式调研时再放入自己的资料。

## 一、安装一次

1. **[点这里下载 ZIP](https://github.com/y1536103801-ui/d11-research/releases/latest/download/d11-research-mac.zip)**，解压后打开 `d11-research-mac` 文件夹。不用登录 GitHub。
2. 双击 `install-mac.command`。它默认把同一个技能装进这台 Mac 的 Codex 和 WorkBuddy 用户技能目录，不会安装这两个客户端本身。只装了其中一个客户端也可以用。
3. 等窗口出现「安装完成」。平时不需要管理员权限。安装器优先用可用的 Python；若已有 Python 但缺少图片或 Word 组件，就放进独立环境。如果机器没有合适的 Python，会从 [Astral 官方](https://docs.astral.sh/uv/guides/install-python/) 下载本工具自己的 Python 3.12。首次下载需要联网。
4. 在 Codex 或 WorkBuddy 中选一个本地工作文件夹，例如在「文稿」新建「男护调研」，然后开启新对话。WorkBuddy 请选择**本地任务**，不要在网页版或云端任务中找这台电脑的文件。

如果双击没运行：打开 Mac 的「终端」，输入 `cd `（末尾有空格），把解压后的文件夹拖进终端并回车，再输入 `bash install-mac.command`。不需要关闭 Mac 的安全设置。

## 二、用一份虚构材料检查安装

> 用 d11-research 在当前工作文件夹跑一次离线演示。完成后给我 Word、候选图片清单和待补清单的位置。

打开 Word，能看到「试跑」和虚构候选商品；待补清单里没有真实平台价格。这一步不必登录电商网站，也不能用来判断电商采集是否成功。

## 三、开始真实工作

先把这句话原样发给助手：

> 用 d11-research 新建一个控油洁面试跑批次，先找自然堂男士控油洁面以及欧莱雅同用途竞品。查天猫、淘宝、京东，先给我看候选商品、参考图片和每支容量。只把与在售详情对得上的渠道图、活动价和优惠写进报告。

接着做三件事：

1. **认款。** 看候选图，告诉助手“选绿泥版 120g 单支”。包装相似时，要同时指出容量和件数。若要用于正式交付，请让它新建**正式批次**并在其中确认；试跑保留为试跑，不会自动变成正式资料。
2. **补证据。** 有商品页就给商品链接；页面不方便打开，也可把商品图或优惠截图放在工作文件夹，告诉助手文件名。需要登录时在平台窗口自己登录，不把密码或验证码发到对话。截图能证明画面上的内容，但不算程序已自动采到该页面。
3. **收结果。** 发：“把本批已核实的资料导出成 Word 和两套图片目录，把缺的字段单列，并给我文件位置。” 新正式批次默认覆盖四个品线和天猫、淘宝、京东；缺少证据的文件夹可能是空的。旧批次沿用原范围，切换范围需另建批次。

| 打开哪个文件 | 看什么 |
| --- | --- |
| `候选清单.html` | 先看是不是对的款、对的规格。 |
| `双十一调研.docx` 或 `双十一调研（试跑）.docx` | 看图文结果及价格、会员券、赠品和竞品对照。 |
| `证据表.html`、`待补.txt` | 查数字从哪来、什么还缺。 |
| `双十一/`、`产品图（更新）/` | 只取已满足对应归档条件的图。试跑以试跑目录和说明为准。 |

下次继续时，**选回同一个工作文件夹**，发：“用 d11-research 读取上次批次的状态，继续补资料，不要重新建批次。” 换 Mac 只安装工具不会同步工作：需另外复制自己的**完整批次目录**，包括隐藏文件和「留证」，再在新 Mac 指明它的位置。不要把私人批次提交到公开仓库。

## 找不到技能或要更新

- **Codex：** 在新对话输入 `$d11-research`；如果列表没刷新，退出并重新打开 Codex。默认安装位置为 `~/.agents/skills/d11-research`。[OpenAI 官方技能说明](https://learn.chatgpt.com/docs/build-skills#where-codex-loads-local-skills)
- **WorkBuddy：** 新建本地任务，说「使用 d11-research 大促调研助手」。默认放在 `~/.workbuddy/skills/d11-research`。如企业版本只识别项目技能，用下面的项目安装命令，再用 WorkBuddy 打开该项目；企业版也可在技能管理里导入 `skills/d11-research`。[腾讯云技能说明](https://cloud.tencent.com/document/product/1831/137452)
- **更新：** 下载新 ZIP，再运行一次安装器；Git 用户在仓库运行 `git pull --ff-only` 后再安装。相同版本会跳过，替换旧技能时会提示备份位置。自己的批次保存在工作文件夹中。
- **安装时网络失败：** 确认能打开 GitHub；缺 Python 依赖时还需访问 Python 软件包源。网络恢复后重跑同一条安装命令。已有 Codex 文档运行环境的 Mac 往往能直接复用。

## 给想用命令行的人

在解压的仓库目录中执行。以下示例均只在本机写文件：

```bash
# 只安装到一个客户端（二选一）
bash install-mac.command --host codex
bash install-mac.command --host workbuddy

# 仅装到指定项目；适合企业版 WorkBuddy 或想和其他项目隔开时
bash install-mac.command --project "$HOME/Documents/男护调研"

# 检查环境，再用虚构材料生成 Word（自动创建新的“工作区/离线演示-...”）
bash skills/d11-research/scripts/run doctor
bash skills/d11-research/scripts/run demo

# 为自己的商品建试跑；去掉 --pilot 即为四品线正式批次，应使用另一个新目录
bash skills/d11-research/scripts/run flow --run "$HOME/Documents/男护调研/控油洁面试跑" start --pilot
bash skills/d11-research/scripts/run flow --run "$HOME/Documents/男护调研/控油洁面试跑" status
```

脚本不自带账号、会员身份或平台授权。本次实际可读的京东目录已能保存候选商品卡；天猫、淘宝、京东都还没有完成详情四项的独立核对。抖音不由这批负责，由用户另行处理。[字段及核对方法](../skills/d11-research/references/workflow.md#四项逐页核对)
